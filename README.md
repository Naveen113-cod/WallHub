# WallHUB 🖼️

WallHUB is a full-stack wallpaper application built using the MERN stack that allows users to explore, search, like, favorite, and download high-quality wallpapers. The platform provides a simple and responsive interface for users while offering powerful management features for administrators.

## 🚀 Features

- User registration and authentication
- Browse and search wallpapers by name and category
- Like and favorite wallpapers
- Download wallpapers
- Responsive user interface
- Light mode and dark mode support
- Separate user and admin functionalities
- Admin dashboard for managing wallpapers and users
- Upload and delete wallpapers
- Track application activities and statistics

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, HTML5, CSS3  
**Backend:** Node.js, Express.js  
**Database:** MongoDB   
**Cloud Storage:** Cloudinary  
**Tools:** Git, GitHub, VS Code, Postman

## 🔄 Application Workflow

Users can create an account, explore available wallpapers, search based on categories, save favorites, and download their preferred wallpapers. Admins have control over wallpaper management, user management, and application monitoring through the admin dashboard.
